아직 스타일(CSS)은 배우지 않았습니다. **구조만** 만들어 달라고 요청합니다.

```
너는 금융권 프론트엔드 개발자다.
은행 앱의 "계좌 카드" 화면 구조를 HTML만으로 만들어 줘.

[표시 내용]
- 은행명 (제목)
- 계좌번호 (마스킹된 텍스트)
- 잔액

```
