# 3교시: 실습 - AI로 페이지 뚝딱 만들기

## 학습 목표

- 프롬프트를 구체적으로 작성하여 원하는 UI를 한 번에(또는 두세 번의 피드백으로) 완성한다.
- AI가 짜준 코드를 실행해 보고, 문제가 생겼을 때 어떻게 프롬프트를 수정해야 하는지 깨닫는다.

## 1. 프롬프트 엔지니어링 팁 (프론트엔드용)

**A. 프레임워크 명시하기**

> "MUI 최신버전을 사용해서 만들어줘. CDN을 포함한 단일 HTML 파일로 작성해."
> 방지 효과: 구버전 코드, 알 수 없는 CSS, React/Vue 같은 프레임워크 코드 지양.

**B. 구조와 디자인 구체적으로 묘사하기**

> "상단에는 파란색 배경의 네비게이션 바(로고와 '로그인' 버튼)가 있고, 중앙에는 메인 콘텐츠를 입력할 수 있는 폼(Card 형태)을 만들어줘."
> 방지 효과: 원하는 레이아웃과 동떨어진 결과물.

**C. CSS보다 Class 사용 권장하기**

> "가능한 한 MUI의 기본 utility 클래스(마진, 패딩, 텍스트 정렬 등)를 사용하고 `<style>` 태그 안의 커스텀 CSS는 최소화해줘."
> 방지 효과: 코드가 너무 길어지고 나중에 수정하기 어려워지는 현상 방지.
